# Generated product audio

`Generated/`のWAVは`ProductProjectGenerator`が数式波形から決定論的に生成する、
Trump Game Lab所有の音源です。外部sample、生成service、第三者assetは使用していません。

- mono / 44.1 kHz / PCM16
- music loop 1件
- semantic UI・match・result・error SFX 10件

WAVを手編集せず、Unityの`Trump Lab > Regenerate Product Scaffold`またはcommand-line generatorで
再生成してください。同じgeneratorから同じbyteが得られ、差分がないfileは書き換えません。
