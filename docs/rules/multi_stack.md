# Multi Stack監査記録

状態は`Verified`。資料は[ゴクラキズムの完全規則](https://gokurakism.com/multi_stacks/)
（参照日: 2026-08-15）。掲載された2～4人協力戦を採用する。

| 項目 | 完全規則 | `MultiStackGame` |
|---|---|---|
| 初期状態 | Jokerなし52枚、公開手札4枚。stackは4人=5、3人=3、2人=2 | 人数別に同数を公開し、残りを秘密stockとする |
| 手番 | 0枚以上補充（上限8）、±1を役条件付きで1枚以上play、任意で1枚譲渡 | `draw`→`play_to_stack`/`finish_play`→`give`/`keep_all`へ逐次Action化 |
| 接続・役 | AはK/2へ接続。同色、色交互、上昇、下降。Jで役を時計回り移動 | 循環rankと4役を実装。3人はdummy役込み4役巡回、2人は同色/色交互だけを交換 |
| 終了 | 全公開手札が空なら勝利、全員がplay不能なら敗北 | 全手札0または全員連続停滞で同じ判定 |

CPUも参照しない。2人戦でJが4人用の上昇/下降役を持ち込む差を修正した。
