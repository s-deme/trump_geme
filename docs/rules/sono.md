# ソノ検証仕様

## 出典と採用variant

配布元・競技団体による公式ルールブックは確認できなかった。したがって、ゲームのカード構成から
得点までを連続して記すゴクラクテンの[ソノ ルール](https://gokurakism.com/sono/)を信頼できる
採用資料とした。参照日は2026年8月15日、採用variantは同資料の2人・25枚・縦列対横列版である。

## 項目別照合

| 項目 | 資料 | 採用仕様とRuntime照合 |
|---|---|---|
| 人数 | 2人 | Registryと`SonoGame`は2人専用。 |
| 使用カード | 各suitのA・9・10・J・Q・K（24枚）とJoker 1枚 | constructorが同じ25枚を生成する。 |
| 配札 | 各10枚を非公開手札、残5枚を5×5盤面の対角線へ伏せて配置 | `hands`と対角位置`0,6,12,18,24`で保持する。 |
| 開始状態 | 縦列・横列の担当を決め、non-dealerから始める | P0=縦列、P1=横列、P0開始へ正規化する。 |
| 全フェーズ | 隣接配置を20回、伏せ対角札の公開、完成盤面の列採点 | `place`、`RevealDiagonals()`、完成時の全10列採点で遷移する。 |
| 合法手 | 既存札に上下左右で隣接する空きへ、自分の任意手札を置く | `LegalActions()`が全手札×全隣接空きを列挙する。 |
| 特殊札・例外 | 対角札は隣接する2辺に札が置かれるまで非公開。Jokerは任意札として役を作る | `revealed`と二つ以上の隣接判定、全置換候補で最大役を取る`LineScore()`に対応する。 |
| 勝敗 | 5×5完成後、縦列担当と横列担当の合計が高い側の勝ち | `Result()`が高得点者（同点なら両者）を返す。 |
| 得点 | ペア1、ツーペア2、3枚3、フルハウス／ストレート5、4枚6、5枚10。赤／黒／数札／絵札の各クランは+3（重複可） | `ScoreConcrete()`がこの役・クランを加算する。 |
| 終了条件 | 25マスが埋まった時点 | `board.All(...)`で終了する。 |
| ローカルルール | 記載なし | 盤面担当と初手のみ決定論的なP番号へ固定し、追加optionは持たない。 |

## CLI/Unityへの正規化

物理的なdealer決めと縦横の担当決めは、P0/P1のラベルを交換するだけの対称な外部手順であるため、
P0=non-dealer・縦列として固定した。任意のカード・配置先・Jokerの役選択は`Action`または役の
最大化に残り、ゲーム上の選択肢は失われない。伏せ対角札は`View`で`?`とし、公開後だけカードを表示する。

## 実装・テスト・差分

`SonoGame`は資料との差分なし。`SecondRuleAuditTests.SonoFixedSeedRevealsAndScoresTheCompletedGridIncludingJokerClan`
はseed 210で隠し対角札、20回の配置、終了採点とJokerの5枚役＋クランを確認する。同
`SonoViewAndCpuIgnoreTheOtherPlayersHiddenHand`は相手の非公開手札順を変えてもP0のView、合法手、CPU選択が
観測同値であることを確認する。

未解決差分はない。
