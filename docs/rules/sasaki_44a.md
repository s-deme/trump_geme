# 44A（ササキ）監査記録

状態は`RuleSpecific`。資料は[GIVE-ME-THE-TRICKの詳細規則](https://give-me-the-trick.blogspot.com/2019/02/44a.html)と
[ゴクラキズム](https://gokurakism.com/44a/)（参照日: 2026-08-15）。round内の組、特殊役、順位精算を採用範囲として確認した。

Runtimeは48枚、赤10による2対2/1対3、基本組、Triple/44A/Four/赤豚/黒豚、kick/stab、
順位別得点とrun/stop倍率を持つ。しかし完全に近い資料にもgame終了条件が未確定と明記され、
Runtimeは1 roundで終了する。また公開規則ではrun時に赤team 2人がD10/H10を交換し、playは時計回りだが、
Runtimeは交換せず反時計回りに進む。3差分が残るためseed 1003完走だけでは昇格せず、`RuleSpecific`を維持する。
